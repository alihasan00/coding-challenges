# Coding Challenges Solutions

This repository contains solutions to coding challenges from John Crickett.

## Structure

Each challenge has its own branch:

- **`go-wc`** - Word count implementation in Go

## Challenges

### Word Count (go-wc)

Implementation of word count functionality in Go, including:

- Counting bytes in a file
- Counting lines in a file
- Counting words in a file
- Counting characters in a file

## Usage

Switch to the appropriate branch to view the solution for each challenge:

```bash
git checkout go-wc
```
